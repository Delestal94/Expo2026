# Spec Delta: Project Roadmap & Timeline

## ADDED Requirements

### Requirement: Interactive Roadmap Presentation
The web application SHALL provide an interactive roadmap view at `/roadmap`.

#### Scenario: Visualizing phased delivery
- **GIVEN** a user on `/roadmap`
- **WHEN** the page is loaded
- **THEN** all 4 delivery milestones (Phase 0 to Phase 3) are rendered with dates, deliverable checklists, and status badges.

# Spec Delta: Interactive Fairgrounds Map

## ADDED Requirements

### Requirement: Fullscreen Fairgrounds Navigation
The web application SHALL provide a fullscreen interactive navigation view at `/mapa`.

#### Scenario: User inspects live pavilion sessions
- **GIVEN** a visitor on `/mapa`
- **WHEN** selecting an auditorium or pavilion
- **THEN** current speaker details and live session status are displayed.
